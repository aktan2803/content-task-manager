Пошаговая инструкция за 3 минуты

💡 Сейчас включен локальный режим (fallback)

Сайт полностью работает прямо сейчас! Файлы сохраняются в локальную папку uploads/. Чтобы файлы автоматически падали в ваш Google Диск, выполните шаги ниже:

  1. Создайте сервисный аккаунт в Google Cloud:
    Перейдите в Google Cloud Console, создайте проект, включите Google Drive API и создайте сервисный аккаунт (Service Account).
  2. Скачайте ключ JSON:
    Во вкладке Keys сервисного аккаунта создайте ключ JSON и сохраните его в корневую папку сайта как service_account.json.
  3. Создайте папку на Google Диске:
    Создайте любую папку на вашем Google Диске (например: "Правки сайта"), нажмите "Поделиться" и добавьте email вашего сервисного аккаунта (xxx@xxx.iam.gserviceaccount.com) с правами Редактор.
  4. Укажите ID папки:
    Скопируйте ID папки из адресной строки Google Диска и вставьте его в файл .env в строке: 
    GOOGLE_DRIVE_FOLDER_ID=1AbC_xyz123yourFolderIdHere
