# 🚀 ContentHub — Сервис обработки запросов на обновление контента

Веб-приложение для приема и обработки задач по обновлению контента на сайте с автоматической загрузкой документов в **Google Диск** и интерактивной панелью задач со статусами и галочками выполнения.

---

## 🌟 Основные возможности

1. **Форма для клиентов / коллег (`/`)**:
   - Поля: Имя заказчика, контакты (Telegram/тел/почта), адрес страницы сайта, описание задачи, приоритет (обычный/срочный).
   - Drag-and-drop загрузка документов (`.docx`, `.doc`, `.pdf`, архивы).
   - Автоматическая отправка файла прямо в **Google Диск** (с fallback-сохранением на сервере, если ключ Google еще не указан).
   - Красивое подтверждение с номером задачи и ссылкой на загруженный документ.

2. **Панель задач для администратора (`/admin`)**:
   - Защита паролем (по умолчанию `admin123`, легко настраивается в `.env`).
   - Сводка статистики (Всего заявок, В очереди, В работе, Выполнено).
   - **Интерактивные галочки (чекбоксы)**: клик по галочке сразу отмечает задачу как «Сделано» без перезагрузки страницы (через AJAX).
   - Прямая кнопка **«Открыть в Google Диске ↗»** — открывает прикрепленный документ в Google Docs/Google Drive.
   - Фильтры по статусам («Все», «Нужно сделать», «В очереди», «В работе», «Сделано») и живой поиск.
   - Поле для быстрых рабочих заметок веб-мастера к каждой задаче.
   - Возможность удаления выполненных/ненужных задач.

3. **База данных**:
   - Автономная SQLite (`tasks.db`), не требует установки отдельных СУБД.

## ⚡ Быстрый запуск

### Вариант 1 (В один клик для Windows):
Просто запустите двойным кликом файл:
```bat
run.bat
```
Он сам запустит веб-сервер и откроет страницу в браузере.

### Вариант 2 (Через терминал):
```powershell
cd C:\Users\User\.gemini\antigravity\scratch\content-task-manager
.\venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

- Клиентская форма: **http://localhost:8000**
- Панель управления: **http://localhost:8000/admin** (Код доступа: **`7788`**)

## 📁 Настройка Google Диска (3 простых шага)

По умолчанию сайт уже работает и сохраняет файлы в локальную папку `uploads/`. Чтобы файлы автоматически загружались в ваш Google Диск:

### Шаг 1. Создайте сервисный аккаунт в Google Cloud
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект (или выберите существующий).
3. В боковом меню перейдите в **APIs & Services** -> **Library** (Библиотека), найдите **Google Drive API** и нажмите **Enable** (Включить).
4. Перейдите в **APIs & Services** -> **Credentials** -> нажмите **Create Credentials** -> выберите **Service Account**.
5. Задайте любое имя (например `drive-uploader`) и нажмите **Done**.

### Шаг 2. Скачайте JSON-ключ
1. Нажмите на созданный сервисный аккаунт в списке.
2. Перейдите на вкладку **Keys** (Ключи) -> **Add Key** -> **Create new key** -> выберите формат **JSON**.
3. Скачанный файл сохраните в папку проекта с именем:
   ```
   service_account.json
   ```

### Шаг 3. Создайте папку на Google Диске и дайте доступ
1. Откройте ваш [Google Диск](https://drive.google.com/) и создайте папку (например, `Заявки с сайта`).
2. Нажмите на папку правой кнопкой мыши -> **Поделиться** -> вставьте email сервисного аккаунта (он выглядит как `xxx@xxx.iam.gserviceaccount.com` и написан в вашем json-файле) с правами **Редактор**.
3. Скопируйте ID папки из адресной строки браузера:
   `https://drive.google.com/drive/folders/`**`1aBcDeFgHiJkLmNoPqRsTuVwXyZ`**
4. Откройте файл `.env` в корне проекта и вставьте ID папки:
   ```ini
   GOOGLE_DRIVE_FOLDER_ID=1aBcDeFgHiJkLmNoPqRsTuVwXyZ
   ```

Готово! После этого все загружаемые клиентами документы будут автоматически сохраняться в вашу папку на Google Диске, а в панели администратора будут генерироваться прямые ссылки на Google Docs.

## 🔒 Безопасность и настройки (`.env`)

Все параметры можно изменить в файле `.env`:

```ini
# Заголовок сайта
APP_TITLE="Центр запросов на обновление контента"

# Порт и хост
HOST=127.0.0.1
PORT=8000

# Пароль для входа в панель администратора (/admin)
ADMIN_PASSWORD=admin123

# Имя файла сервисного аккаунта и ID папки на Google Диске
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
GOOGLE_DRIVE_FOLDER_ID=
```
